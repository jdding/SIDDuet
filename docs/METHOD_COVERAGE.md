# What has actually run

| Source | Execution | Boundary |
| --- | --- | --- |
| GenSAR | Native joint quantizer; semantic/collaborative complete codes and a shared prefix | Controlled declared features; complete generative system not reproduced |
| ReSID GAOQ | Native quantizer; full code and two prefix depths | Component, not a second joint S&R model |
| UniSAR | Real source implementation and previously trained checkpoint; 166,981 original 100-candidate test requests | Atomic-item model; score-interface evidence on a separate processed KuaiSAR view, not a full-paper quality reproduction |
| Other registry names | Documented export interfaces | Synthetic contract checks do not establish real model execution |

UniSAR's new case joins 5,283 targets to the paired-observation view. The public metric engine matches direct model scoring and reports the full denominator. No neural model is trained in this revision. `reports/model_reuse/` gives all counts, conditional diagnostics, protocol changes and limitations.

The core dataset reference remains KuaiSAR and Qilin. JDsearch's archived query-less history is a proxy extension, not identified recommendation traffic. The processed KuaiSAR case is an input view of an existing dataset rather than a third dataset.

The fixed UniSAR numerical checkpoint is included under its own CC BY-NC-SA4.0 terms. [Full replay](../analysis/model_reuse/REPLAY.md) uses independently acquired upstream source and provider inputs.
