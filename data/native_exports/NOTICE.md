# Sources and notices

Underlying catalog identifiers come from Qilin, THUIR / RED-Search: https://huggingface.co/datasets/THUIR/Qilin and https://github.com/RED-Search/Qilin. The official HF dataset card metadata declares Apache-2.0; the card prose separately calls the project MIT. This package records the dataset metadata and retains Apache-2.0 terms for underlying provider material.

Cite Jia Chen et al., Qilin: A Multimodal Information Retrieval Dataset with APP-level User Sessions, 2025, https://arxiv.org/abs/2503.00501 .

Numeric SID exports were produced in controlled local component runs using the pinned GenSAR and GAOQ implementations recorded by the study. The export is a local research transformation and is not an official upstream model or full-system reproduction. No upstream source code is included or relicensed here. GenSAR semantic and collaborative views are one algorithm, with a common two-token prefix. GAOQ complete codes are unique on this cohort.

This release removes support counts and label diagnostics from the source cohort table, keeps only its catalog item keys, and copies numeric item-to-code exports unchanged. The provenance file supplies content hashes. These approved derived inputs are included in the versioned public releases under the retained provider terms.
